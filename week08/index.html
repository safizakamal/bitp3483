FOUNDATION • BASIC SPATIAL ANALYSIS

How Does GIS Turn a Geographic Question into an Answer?

Before combining proximity and overlay, establish the basic analytical process. GIS analysis begins with a geographic question, not with a software tool.

QUESTION → DATA → CONDITION / RELATIONSHIP → ANALYSIS → RESULT → INTERPRETATION

Four basic analysis ideas

1. SELECTION
Which features meet a condition?

Example: Which buildings are schools?
2. MEASUREMENT
How much, how long or how large?

Example: What is the area of each affected residential zone?
3. CLIP
Which features or parts occur within my area of interest?

Example: Keep roads located within the study boundary.
4. INTERSECT / OVERLAY
Where do geographic features share the same space?

Example: Which residential areas overlap flood-prone zones?

Attribute condition or spatial relationship?

Geographic questionThinking
Which schools have more than 500 students?ATTRIBUTE CONDITION — based on stored descriptive information
Which residential areas are inside a flood-prone zone?SPATIAL RELATIONSHIP — based on location
How much residential area is affected?MEASUREMENT — quantify the result
Key idea: The spatial relationship is already represented by the locations of features. GIS analysis helps us identify, quantify and make that relationship explicit so that it can be interpreted.
Do not start with: “Which tool should I click?”
Start with: “What is my geographic question, and what condition or relationship must I investigate?”

03 📏 LEARN

Distance & Buffer

A buffer creates a zone at a specified distance around a geographic feature.

FEATURE+DISTANCE→BUFFER ZONE
FeatureExample question
HospitalWhich communities are within 5 km?
RoadWhich schools are within 500 m?
RiverWhich houses are within 100 m?
Industrial areaWhich residential areas are within 1 km?
📍 Point Buffer
〰️ Line Buffer
⬡ Polygon Buffer
Inside a buffer means: the feature satisfies the specified straight-line proximity condition.
It does not automatically mean: the feature is easily accessible or reachable by travelling the same distance.

04 🧠 EXPLORE

Proximity ≠ Accessibility

Buffer / Proximity

Geographic closeness, commonly using straight-line distance.

House → Hospital = 800 m

Actual Accessibility

Movement through roads, paths, entrances and connected networks.

Actual route = 2.3 km

Why might the values differ?

🌊 River barrier
🛣️ Road layout
🚧 Restricted access
🚪 Entrance location
Key distinction: A circular buffer assumes closeness through geographic space. Real travel follows a network.

📘 READING 03

What Makes a Location Suitable?

Criterion

A condition used to evaluate suitability.

Example: Within 1 km of residential areas.

Constraint

A condition that excludes a location.

Example: Must not be inside a flood-prone zone.
  1. What makes a location suitable?
  2. What conditions exclude it?
  3. What threshold will be used?
  4. Can the threshold be justified?
  5. Are the input data reliable and current?
07 ⚖️ JUDGE

Is the “Best” Site Really the Best?

GIS identifies Site A as the most suitable. Is Site A objectively the best location?
Reveal

No. A more defensible statement is: Site A is the most suitable according to the selected data, criteria, thresholds and analytical assumptions.

Test the assumption

Result A
Distance = 1 km
Result B

DATA+CRITERIA+THRESHOLDS+ASSUMPTIONS→GIS RESULT
GIS output is evidence, not automatic truth.

Week 08 Wrap-Up

From Nearby to Accessible

Buffer helps represent what is nearby. Suitability analysis helps identify locations meeting several defined criteria.

But straight-line distance does not tell us how people actually travel.

What route should they take? What is accessible through the road network? What happens when roads are blocked?
